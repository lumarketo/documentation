Cuando una empresa tiene habilitado el **POS externo**, NubeFood notifica cada **orden** enviando un `POST` a la **URL de callback** que configuraste. Este documento describe **el payload que enviamos**.

## La solicitud que enviamos

<>
  <div style={{ display: "flex", alignItems: "center", marginTop: 20 }}>
    <div style={{ display: "inline-flex", backgroundColor: "#674ead", height: "20px", fontSize: "10px", alignItems: "center", borderRadius: "16px", justifyContent: "center" }}>
      <div style={{ display: "flex", alignItems: "center", paddingLeft: "12px", paddingRight: "12px", fontWeight: 600, color: "#fff" }}>POST</div>
    </div>
    <h6 style={{ fontSize: 14, height: 30, marginLeft: 5 }}>&lt;tu-callbackUrl&gt;</h6>
  </div>
</>

- **Método:** `POST`
- **Content-Type:** `application/json`
- **Cuerpo:** el objeto de la **orden normalizada** (ver estructura abajo).
- **Disparo:** por cada orden nueva de la empresa (mientras el webhook esté activo).

Tu endpoint debe responder `2xx` para confirmar la recepción.
